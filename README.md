# Jean Limo — full booking site + tips

This is the original Houston booking website (quote, vehicles, manage booking)
with tip buttons on the pay card.

Tips are a percent of the ride total (10 / 15 / 20 / 25%).

## Deploy

1. Replace ALL files in github.com/jeanlimo999/jeanlimo with this folder (root).
2. Do not leave the extra `app/` checkout-only pages from earlier zips.
3. Netlify env: STRIPE_SECRET_KEY and any existing keys (maps, email).
4. Build command: npm run build
